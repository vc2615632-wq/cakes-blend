CAKES BLEND WEBSITE - SETUP GUIDE
=================================

FILES
-----
1. index.html
2. style.css
3. script.js

HOW TO RUN
----------
Open index.html in any browser.

IMPORTANT CHANGES
-----------------
1. WhatsApp Number:
   Open script.js and replace:
   const WHATSAPP_NUMBER = "971500000000";
   Use country code without +, spaces or dashes.

2. Images:
   Search "image-placeholder" in index.html.
   Replace each placeholder DIV with an image, for example:

   <img src="images/hero-cake.jpg" alt="Chocolate cake">

3. Google Map:
   In index.html, search:
   Your+Cake+Shop+Location
   Replace it with your exact shop address using + between words.

4. Contact Details:
   Update address, phone, email and shop timing in the Contact section.

5. Prices:
   Replace AED prices with your real prices/currency.

6. Social Media Links:
   Replace all href="#" values with your real Instagram, Facebook,
   TikTok and YouTube links.

WHATSAPP AUTOMATION INCLUDED
----------------------------
- Header Order Now button
- Hero Order button
- Every product "+" button
- Every category Explore button
- Customized cake form
- Contact form
- FAQ WhatsApp button
- Floating WhatsApp button
- Footer WhatsApp button

All forms create a pre-filled WhatsApp message automatically.
